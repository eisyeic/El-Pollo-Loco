# El Pollo Loco

**El Pollo Loco** is a fun 2D browser game where you control the courageous Pepe on his quest to defeat wild chickens and collect items. Built with HTML, CSS, and JavaScript, this lightweight game is ideal for showcasing web game fundamentals and simple browser interactivity.

👉 **Play the live demo here:** 
https://davideisenbarth.infinityfreeapp.com/assets/projects/el-pollo-loco/index.html

---

## 🕹️ Game Overview

In *El Pollo Loco*, the player:

- Moves **Pepe** left and right
- Jumps over obstacles
- Collects bottles and coins
- Throws bottles at enemies (chickens) to defeat them
- Faces a boss challenge at the end of the level

The game runs entirely in the browser and adapts to desktop and mobile screens.

## 🚀 Features

- 🎮 **Simple Controls**
  - Left / Right movement
  - Jump action
  - Bottle throwing
- 🐔 **Classic arcade-style gameplay**
- 📦 **No backend required** – purely front‑end game
- 📱 Works in modern browsers on desktop and mobile

## 🧠 How to Play

**Controls**  
- Move left: ← (or `A`)  
- Move right: → (or `D`)  
- Jump: `Space`  
- Throw bottle: `D` key (or mouse tap/click if supported)

Collect all items and defeat enemies to reach the end of the game!
